# dashboard/public/data/

Generated JSON the dashboard app fetches at runtime. Both files are committed so the dashboard
renders immediately from the last refresh, and both are regenerated (never hand-edited).

| File | Regenerated by | What it is |
|---|---|---|
| `dashboard.json` | `scripts/build-dashboard-data.mjs` (`npm run build-data`) | consolidated findings, limits, zones, activity, and betas from the latest snapshot + reports |
| `actions.json` | `scripts/build-actions.mjs` (`npm run actions`) | the verified action backlog (from `config/backlog.json`) that drives the dashboard's Action Center |

Both are produced as part of `npm run refresh`.
