# dashboard/

The unified dashboard: a React + Vite single-page app that reads `public/data/dashboard.json`
(built by `scripts/build-dashboard-data.mjs`) and `public/data/actions.json` (built by
`scripts/build-actions.mjs`), and renders findings, plan limits, zones, activity, and betas in
one view. Never mutates the account; it's a pure reader of already-generated JSON.

| Path | What it is |
|---|---|
| `src/` | the app source, see `src/README.md` |
| `public/` | static assets served as-is, including the generated data, see `public/README.md` |
| `dist/` | build output (gitignored, regenerated by `npm run dashboard:build`) |
| `index.html`, `vite.config.ts`, `package.json` | Vite entry point and config for the real dashboard |
| `demo.html` | a second, independent Vite entry that mounts only `src/components/ui/demo.tsx` - a sandbox for previewing new `components/ui` pieces without touching `index.html`/`App.jsx` |
| `tsconfig.json`, `components.json` | TypeScript and shadcn/ui config, used by `src/components/ui/` and `src/lib/utils.ts` (the main app stays plain JS/JSX) |

Run it with `npm run dashboard` (installs deps on first run, opens at `localhost:5180`).
Visit `/demo.html` on that same server for the component sandbox.
