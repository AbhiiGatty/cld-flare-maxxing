# GitHub Sponsors setup

`.github/FUNDING.yml` already points GitHub's native "Sponsor" button at
`github.com/sponsors/AbhiiGatty`. That profile doesn't exist yet: GitHub Sponsors requires
manual enrollment (identity verification, payout details) at
[github.com/sponsors](https://github.com/sponsors), which only the account owner can complete.
Nothing here can be scripted around that.

Once enrolled, paste these tiers in at
`github.com/sponsors/accounts/AbhiiGatty/dashboard/tiers`.
