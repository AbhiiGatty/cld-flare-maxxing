# assets/brand/

The three brand SVGs used in `README.md`. All three share one mark: the cloud silhouette
(three overlapping circles plus a base ellipse) filled with the orange→amber gradient
(`#f6821f` → `#fbb040`), with a small dark 4-point spark set into it. No bounding square, no
monospace glyph baked into the mark itself, see `docs/DESIGN-SYSTEM.md` for why.
